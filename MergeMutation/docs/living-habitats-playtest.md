# Живой Рогач — ручная проверка PR №16

## Запуск через GitHub Desktop и Godot

1. В GitHub Desktop выбрать репозиторий **merge-mutation** и нажать **Fetch origin**.
2. В Current branch выбрать **feature/living-habitats**. Для проверки не нужно объединять PR. Если есть ваши локальные изменения, не выбирать Discard changes; сначала сохранить работу.
3. **Repository → Show in Explorer** → найти `MergeMutation/project.godot` именно в этой папке.
4. В менеджере Godot **4.7.2** нажать Import → выбрать этот файл → Import & Edit. Если открыт тот же проект, принять Reload внешних изменений. Дождаться импорта.
5. Нажать **F5** → в верхней панели главной лаборатории **КОМПЛЕКС** → перейти на −1.
6. Коротко нажать Рогача. Должна открыться детальная среда, по умолчанию **стадия 2**. «Инфо» показывает прежнюю карточку, «Назад» возвращает в комплекс на прежнее место.
7. Четыре кнопки **СТАДИЯ 1–4** под надписью «ТЕСТОВЫЙ ПРОСМОТР» нужны только для демонстрации обстановки. Это не эволюция вида и не постоянный прогресс.

## Сценарии

| Проверка | Действие | Ожидание |
|---|---|---|
| Масштаб | Просмотреть все пять этажей | На −1 два более крупных вольера, на −2 один средний, на −3 большая камера, на −4 три закрытых; старые навигация/инерция работают |
| Стадия 1 | Нажать 1 | Пустая каменная камера с монитором, мутанта нет, «Позвать» и «Тренировка» отключены |
| Стадия 2 | Нажать 2, подождать 15–30 секунд | Рогач дышит, гуляет, осматривается/спит, присутствуют простые элементы среды |
| Реакция | Нажать Рогача, в том числе спящего | Короткий отклик/прыжок, пробуждение, без окна и навязчивого звука |
| Частые касания | Быстро нажать несколько раз | Нет наложения бесконечных анимаций или многократных запросов в cooldown |
| Стадия 3 | Нажать 3 | Появились новые камни, растения и тренировочный камень |
| Таран | Нажать камень или «Тренировка» | Подход, подготовка, один удар, обломки; камень возвращается примерно через 4 видимые секунды |
| Стадия 4 | Нажать 4 | Видны горный фон, дополнительная зелень/лиана и свет; реакции и таран сохранены |
| Границы | Наблюдать прогулку/таран | Нет выхода за края и прохода сквозь тренировочное основание; лёгкое визуальное касание камня при ударе ожидаемо |
| Общая модель | Выбрать 4, вернуться назад | Тот же этаж и scroll offset, комната подсвечена, её обзор показывает ту же стадию 4 |
| Скрытие | Уйти на другой этаж и вернуться | Не запускаются скрытые анимации; стадия сохраняется в текущем комплексе, поведение продолжится после показа |
| Повторное открытие | Открыть/закрыть вольер 8–10 раз | Нет дополнительных мутантов, зависших окон или потери управления |
| Возврат домой | Выйти в главную лабораторию | Монеты, клетки, коллекция и кампания прежние; новый вход в комплекс снова даёт демо-стадию 2 |
| Регрессия | Запустить тактическое испытание после комплекса | Отмена и длинный маршрут работают, прежние правила/награды не изменены |

Повторить мышью и, при наличии тестовой Android-сборки, пальцем. Проверить попадание непосредственно по мутанту/камню, доступность кнопки возврата, чтение подписей и достаточность площади среды 340×420. Свайп по среде не должен считаться коротким касанием.

## Вопросы тестировщику

Оценить от 1 до 5 и дать свободный комментарий:

1. Помещения теперь ощущаются полноценными, а не миниатюрными клетками?
2. Рогач и основные декорации различимы в обзоре?
3. Деталь воспринимается живой средой, а не информационной карточкой?
4. Четыре стадии отличаются достаточно заметно?
5. Понятно ли, что переключатель тестовый и не меняет эволюцию/сохранение?
6. Поведение выглядит разнообразным и спокойным, а не короткой повторяющейся петлёй?
7. Подход/удар/восстановление камня понятны и приятны?
8. Возврат и сохранение места в комплексе удобны?

Записать устройство, разрешение, способ ввода, стадию и шаги проблемы. Плейтест PR №15 не считается плейтестом новых функций. APK, физический телефон, аппаратный Back, пауза приложения и FPS/память Android в этой работе не проверялись. Автоматический стресс-комплекс 50 этажей проверяет навигацию и активные секции, а не стоимость 50 одновременно живущих мутантов.
