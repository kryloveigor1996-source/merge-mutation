# PR №14 — ручная проверка отмены и прямых маршрутов

Новые функции работают только в тактическом эксперименте. Реальное Android-устройство и APK в этой работе не проверялись; touch-события автоматических тестов не заменяют проверку пальцем на телефоне.

## Запуск для новичка

1. Открыть GitHub Desktop и выбрать репозиторий **merge-mutation** в списке Current repository.
2. Нажать **Fetch origin**. В Current branch выбрать **feature/undo-and-corridor-movement**. Не нажимать Merge into current branch и не объединять PR ради тестирования.
3. Если GitHub Desktop сообщает о ваших локальных изменениях, не выбирать Discard changes. Сначала сохранить их отдельно или сообщить разработчику; тесты не требуют удаления файлов или сохранений.
4. В меню Repository выбрать **Show in Explorer**. В открытой папке найти **MergeMutation/project.godot**. Именно этот проект относится к выбранной ветке; не открывать старую копию из другой папки.
5. В Godot **4.7.2** в менеджере проектов нажать **Import**, выбрать этот `project.godot`, затем Import & Edit. Если проект уже открыт из этой папки, принять **Reload** для внешних изменений. Дождаться завершения импорта.
6. Нажать **F5** (запуск проекта, не F6 для отдельной сцены). В лаборатории нажать **ЭКСПЕРИМЕНТ**.
7. Выбрать испытание. Кнопка **↶ ОТМЕНИТЬ (2)** находится справа от создания, под полем. Список можно прокрутить к 6–10. «В лабораторию» безопасно закрывает режим; пользовательские сохранения не удалять.

## Что изменилось

На попытку выдаются две бесплатные отмены. Каждое успешное действие, включая бесплатное создание, занимает один снимок истории. Ошибка снимка не создаёт. Отмена возвращает состояние перед последней командой и расходует одну отмену; её расход не восстанавливается другой отменой. После проигрыша и победы отмена доступна, если есть снимок и запас. Перезапуск очищает историю и возвращает две отмены. Список/выход удаляют историю попытки.

Число на кнопке — **оставшийся запас**, а не число доступных снимков: если история пуста, кнопка с оставшейся единицей тоже серая. Во время короткой анимации действие временно блокируется, чтобы двойное касание не списало два раза. При отмене поле кратко подсвечивается, выбор существа сбрасывается.

При выборе существа бирюзовая рамка с цифрой **2–5** обозначает дальнюю свободную клетку на прямом маршруте и полную стоимость в ходах. Голубая стрелка — обычный шаг, жёлтый плюс — слияние, оранжевый знак — камень, фиолетовая стрелка — существующий прыжок. Дальний маршрут не разбивает камни, не сливает существ и не использует полёт. Кислота допустима только Слизику. Сохраняются отдельные прыжки через разрыв по прежней фиолетовой подсветке.

## Сценарии приёмки

| Сценарий | Действия | Ожидаемый результат |
|---|---|---|
| Пустая история | Открыть любое испытание | Видно 2, кнопка серая |
| Создание | В 1 создать Рогача и отменить | Исчезает созданный Рогач, создание снова доступно, ходов всё ещё 0, запас 1 |
| Камень | В 1 выбрать левого Рогача, нажать соседний камень, отменить | Камень восстановлен, Рогач на прежнем месте, ход возвращён |
| Прыжок и слияние | В 3 прыгнуть с левой клетки через щель, объединиться справа, отменить | Победа отменена, обе формы I восстановлены, последний ход возвращён; ещё одна отмена возвращает Крылатика через щель |
| Поражение | В коротком испытании потратить лимит на возвраты и затем отменить | Показана понятная причина проигрыша; кнопка доступна после анимации; отмена возвращает активную попытку и ход |
| Две отмены | Сделать два шага, отменить дважды, снова сделать шаг | Ноль отмен; третья попытка отменить не действует даже с новой историей |
| Перезапуск | Израсходовать отмену и нажать «Заново» | Исходная раскладка, две отмены, пустая история |
| Дальний маршрут | В 8 выбрать верхнего левого Рогача, нажать клетку его цели на две клетки ниже | Подсвечена цифра 2, списаны два хода; одна отмена возвращает обе клетки и оба хода |
| Ошибка маршрута | Пробовать диагональ, занятую клетку вдали, камень, разрыв или кислоту Рогачом | Нет частичного движения и списания ходов; нет нового снимка истории |
| Разные способы ввода | Повторить движение и отмену мышью, затем touch при наличии сборки | Один жест — одна команда; перетаскивание на камень его не разбивает |
| Выход | Сделать ход, выйти в список/лабораторию и снова открыть испытание | Старые действия отменить нельзя; прогресс кампании и монеты прежние |

Если цель достигается на промежуточной клетке, обычные шаги уже завершили бы уровень. Команда, пытающаяся пройти дальше этой победы, отклоняется целиком: выберите саму целевую клетку. Это сохраняет эквивалентность обычным шагам.

## Короткая анкета

Оценить каждое утверждение от 1 до 5 и добавить комментарий:

1. Кнопку отмены легко найти и нажать, она не мешает полю.
2. Понятно, почему кнопка иногда серая при оставшемся запасе.
3. Понятно, что цифра на дальней клетке означает стоимость всего пути.
4. Дальнюю клетку удобно выбрать без случайного движения.
5. Движение через несколько клеток ощущается быстрым, но предсказуемым.
6. После проигрыша понятно, как вернуться в игру отменой.
7. Две бесплатные отмены помогают исправлять ошибки, сохраняя интерес головоломки.

Записать устройство, разрешение, способ ввода, номер испытания, что ожидалось и что произошло. Отдельно проверить на телефоне размер кнопок 148×44 / 152×44 и читаемость цифр на поле. Человеческие результаты этого плейтеста пока не получены.
