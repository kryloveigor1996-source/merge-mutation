## Установка обновлением

APK находится в `builds/android/merge-mutation-pr22.apk` относительно Git-корня. Package ID прежний: `org.mergemutation.prototype.debug`; versionCode увеличен до 22. Использован прежний стандартный debug-сертификат редактора, без production-ключей.

Скопировать APK на телефон и открыть для обновления либо выполнить `adb install -r "C:/Users/User/OneDrive/Documents/ChatGPT/Games/MergeMutation/builds/android/merge-mutation-pr22.apk"`. Не удалять PR21 перед установкой: удаление приложения удаляет сохранения. При конфликте сертификата остановиться и сохранить данные, а не автоматически делать uninstall/clear data.

Проверить сохранность монет, биокапсул, коллекции, кампании, ремонта и громкости **до** входа в новый режим. Инструмент check_android_build сравнивает подпись и пакет, но фактическое обновление на устройстве в этой среде не проверено: adb и AVD пусты.
