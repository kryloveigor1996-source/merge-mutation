# Portrait First — план проверки после согласования

Сейчас доступны только макеты. APK23 из PR22.1 уже прошла предоставленный пользователем физический тест15/15,4.25/5. Новый интерфейс/APK24 на телефоне ещё не существует и не проверялся.

## Согласование композиции

Открыть `portrait-review/index.html` в браузере. Выбрать каждый из6 экранов; сравнить9:16/9:19.5, включить размеры touch/safe-area, при желании сравнение с PR22.1. Проверить переходы room→habitat, nav, досье/поиск, раскрытие целей/предпросмотра. Это кликабельные материалы, не игровые команды.

Утвердить или поправить:разрез комплекса; поле и нижние действия; крупный обитатель/широкая камера/нижняя панель вольеров; иерархия архива; разделение портального зала. Текущая временная графика не утверждается как финальный арт.

## Матрица после реализации

| Размеры portrait | Landscape | Insets / density |
|---|---|---|
|360×640,360×720,360×800 |640×360,720×360,800×360 |Явно задавать dpWidth и density; числа viewport не автоматически dp|
|412×915 |915×412 |Слева/справа асимметричные safe-area|
|540×960,540×1170,540×1200 |960×540,1170×540,1200×540 |Жестовая и кнопочная системная навигация, вырезы|

Измерять реальный полезный прямоугольник и84 ед.вdp на устройстве; minimum48dp. Отдельно большой шрифт, длинные названия/цели, все состояния модальных панелей. Приводить площадь field/комнаты/навигации, а не только отсутствие выхода за экран.

## Регрессии

- Все30 уровней и доказанные решения/цены, прежние тесты PR22.1; два tap, отсутствие drag/hold, невозможная диагональ, multitouch, повторные касания, Undo.
- Все помещения/этажи/лифтовые маршруты, culling при большом числе этажей, плавный вертикальный скролл без случайных входов.
- Все6+10 слотов вольеров, выбор существующего дизайна, отмена/установка, точная цена, бесплатная смена, наблюдения, автономность/декорации, прежние сохранения.
- Camera x/y для подходящих профилей, пределы, zoom, «Найти», выбор зоны/объекта, ручное прерывание автофокуса, соответствие view/world hitboxes.
- Архив:поиск/фильтр/пять стадий/свитокдосье, скрытые имена/стадии, реальный прогресс, переход в известный вольер.
- Лабораторный стенд, другие миры/условия, обе экспериментальные кампании и песочница; туман/предпросмотр и отсутствие повторных наград.
- Back, непрозрачность панелей/блокировка фона, пауза/возврат/поворот, ориентация существующего профиля, portrait нового, аудио/подсказки.

## Android после реализации

Собрать `builds/android/merge-mutation-pr23.apk`, versionCode24 или выше установленного, прежниеpackage/certificate. Установить `adb install -r`, без удаления приложения. Сверить баланс/прогресс/коллекцию/установки/громкость до/после. Записать физические размеры кнопок, частоту ошибочныхtap, понятность поискаобъекта, FPS и отзывчивость.

Нужны реальные скриншоты/видео на Galaxy; Windows GPU/synthetic touch подписывать отдельно. Только после всех автоматических проверок/реализации открыть PR23. Не merge автоматически, не начинать PR24 до ручного Android-плейтеста.
