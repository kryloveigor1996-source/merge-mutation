# Экспериментальные механики PR22

Поле 5×6. Все новые правила действуют только в Tactical Evolution. Цели перечислены в `objectives`; победа требует выполнения **всех**. Старое поле `goals` сохраняется для контракта базового валидатора, но не подменяет новые цели.

| Цель | Что засчитывается |
|---|---|
| create | Фактически созданная форма заданного вида/минимальной стадии; стартовый мутант не считается созданием |
| evacuate | Подходящее существо вошло в портал и удалено с поля; форма/вид записаны в попытке |
| collect | Уникальные образцы, поднятые существом при входе в клетку |
| activate | Уникальные приборы/механизмы, успешно активированные отдельным действием |
| neutralize | Уникальные аномалии, ликвидированные подходящим видом/стадией и при выполненных условиях |
| Комбинация | Несколько записей objectives; каждое условие обязательно |

## Действия и стоимость

Обычный соседний шаг, слияние, таран, толкание, обнаружение, активация и нейтрализация стоят 1 ход. Длинное прямое перемещение стоит длину пути; это одна команда Undo с несколькими обычными шагами. Создание не тратит ходы, но ограничено sequence/creation_limit и свободным инкубатором. Даже при нуле оставшихся ходов допустимое бесплатное создание может завершить цель. Неуспешное действие не тратит бюджет и не создаёт историю.

Путь проверяется до фиксации. Нельзя пересечь занятую клетку, камень, закрытый шлюз, недопустимую кислоту или разрыв. Дальнее слияние не подменяет обычный соседний merge. Победа/эвакуация в середине длинной команды не позволяет продолжить движение отсутствующего существа.

## Способности

- Слизик проходит кислоту. Остальные не могут в неё войти.
- Рогач разбивает соседний камень либо толкает ящик на одну клетку. Ящик нельзя протолкнуть через существо, камень, шлюз или край поля. Рогач занимает освобождённую клетку ящика.
- Крылатик перескакивает один разрыв по горизонтали/вертикали с допустимым свободным приземлением. Стоимость прыжка — 1, как в прежнем эксперименте.
- Глазастик обнаруживает соседний скрытый механизм. Обнаружение и активация — отдельные действия. Другой обитатель может активировать уже видимый механизм, если конфигурация не требует определённого вида.

## Окружение и связи

Объект: стабильный id, type, cell, необязательные species_id/stage/channel. Типы: plate, gate, crate, portal, sample, equipment, hidden, anomaly. `circuits` связывает входные IDs плит/приборов/механизмов с режимом all/any. Шлюз, портал, прибор или аномалия могут требовать активный канал.

Плита активна только при наличии существа или ящика. При уходе питание исчезает. Закрывающийся шлюз не уничтожает уже находящегося на нём обитателя: ему разрешён выход. Активация оборудования защёлкивается до Undo/перезапуска. Скрытый механизм не рисуется до обнаружения; выделение Глазастика показывает доступное обнаружение, без автоматического решения уровня.

Образец не собирается ящиком. Портал проверяет вид/стадию до входа. Аномалия блокирует клетку до нейтрализации. Требования берутся из конфигурации; код не содержит условий по номеру конкретного уровня.

## Undo и solver

Переиспользованы две бесплатные отмены MutationHistory. Снимок содержит существа, terrain, ящики, состояния приборов/обнаружения/образцов/аномалий, эвакуации, созданные формы, счётчики ходов/созданий и status. После отмены победы результат исчезает; постоянных наград не было.

Dijkstra использует точные apply_action и fork. Создание имеет вес 0, остальные примитивы — 1. Доминирование выполняется только для полного одинакового состояния с меньшей потраченной стоимостью. Длинные команды не нужны solver: эквивалентная последовательность примитивов даёт тот же минимум. Ограничение поиска не интерпретируется как доказанная нерешаемость; все десять авторских уровней решены без cutoff.

Новые виды задач/объектов добавляются в общий валидатор, диспетчер действий/проверки целей и рендерер. JSON определяет конкретную композицию уровня. Основная кампания и её награды не изменялись.
