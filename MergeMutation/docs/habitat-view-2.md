# Habitat View 2.0 — камера и режимы

`mobile_habitat.gd` сохраняет CoreHabitat/renovationState и все ID/цены/дизайны; `mobile_camera.gd` управляет представлением, `mobile_environment.gd` рисует исходную комнату/декорации/PNG. Новый `data/habitat_views.json` содержит только параметры представления, version1.

## Три состояния

Наблюдение — начальное, без постоянного upgrade HUD, шапка/поиск/настройки. Касание площадки или установленного объекта открывает обустройство: выбор дизайна/стоимость/подтверждение/отмена. Взаимодействие установленного объекта вызывает прежнюю модель. Список объектов позволяет достичь перекрывающихся площадок. Резервирование панели сокращает viewport камеры, чтобы фокусируемый объект не прятался под ней.

Обзор зон появляется только при ширине мира>=1400. Список реальных объектов, точки фокусировки, zoom+/−, поиск мутанта. В текущей конфигурации обе комнаты S=940: постоянно показывать обзор зон здесь не требуется. Ранние документы/макеты ссылались на старую широкую композицию Рогача2350; фактические `ecosystems.json`/registry не расширялись ради интерфейса. Для будущих M/L/XL архитектура и синтетические тесты готовы.

## Параметры и сохранение

Границы берутся из реального registry, высота420 для текущих плоских комнат. Стартовый фокус — обитатель, центр, slot или координата из config. Масштаб определяется долей видимой ширины, не высотой; Слизик80%, Рогач76%. Увеличение системного экрана и поворот пересчитывают базовый масштаб с сохранением относительного пользовательского zoom. Пределы, axes, focus_points, тип S/M/L/XL настраиваются отдельно.

Плоские комнаты: осьx, земля нижней части viewport; стены/растения/объекты проецируются представлением, поведенческие координаты и collision остаются прежними. Маркеры/hit/focus используют одно преобразование. Будущие высокие комнаты с axes[x,y] используют двумерную камеру без плоской проекции; тест обратного преобразования и обоих pan-направлений есть, полноценный новый многоуровневый вольер не создавался.

CameraConfig сохраняется по habitat_id в `[habitat_camera_v1]` прежнего ConfigFile, отдельно от кошелька/прогресса. Неизвестная версия/NaN/неподходящие bounds отвергаются; существующие игровые saves не мигрируются. Pan отменяет автофокус, bounds ограничивают движение, маленький мир центрируется. При паузе/настройках симуляция detail и фоновых превью останавливается; невидимые этажи сохраняют culling.

## Проверено

Все16 объектов доступны и установлены по прежней цене; бесплатная смена дизайна, preview cancel, камера/перезапуск/старые v2 saves и наблюдения. Синтетическая увеличенная комната включает зоны; будущая высокая — обе оси. Windows touch/mouse проверены отдельно от обязательной физической Android-приёмки.
