# PR23 — Mobile Redesign: Portrait First

Композиция A утверждена пользователем. Реализована в `feature/portrait-first-redesign` поверх `98d1d37`; база main `6d8fa83` включает PR22 и Mobile Control Fix. PR24 не начат. Эта документация заменяет статус ожидания согласования; исходные согласованные макеты сохранены в `portrait-review/`.

## Реализовано

- Общая адаптивная тема, контейнерные шапки/ресурсы/навигация, карточки, прокручиваемые модальные окна и панели. Базовая ширина540, высота от полезного viewport; safe area применяется один раз. Новый профиль portrait, существующая настройка ориентации сохранена.
- Комплекс остаётся разрезом сооружения: непрерывная шахта, стены/перекрытия, этажи, лифт, крупные комнаты и видимые обитатели. Сохранены registry/culling и остановка невидимых/закрытых сцен.
- Три головоломки используют общий shell: краткие цели с подробностями, максимально широкое квадратное поле, реальные действия/стоимость, Undo и инкубатор только при наличии. Перезапуск отделён и требует подтверждения. Два нажатия сохранены; удержание/свайп не перемещают мутантов.
- Вольеры: наблюдение по умолчанию, обустройство по объекту/площадке, обзор зон только для больших комнат. Панели не занимают место постоянно. Существующие объектные рисунки/PNG переиспользованы, координаты поведения и экономика не меняются.
- Бестиарий: поиск/фильтр, реальные досье, стадии, способности и полученные наблюдения. Неизвестные — непрозрачные силуэты с вопросами; скрытые сведения не раскрываются.
- Порталы: отдельный лабораторный стенд, другие миры в карусели, экспериментальные режимы отдельно. Старые world/level IDs, блокировки, карты, туман, preview, переходы и награды сохранены.
- Истории, результаты, настройки звука и песочница адаптированы к новым размерам. Settings/Back возвращают тот же поиск/досье. Контекстные подсказки находятся вне поля и основных кнопок.

## Проверки и ограничения

Godot4.7.2.stable.steam.ed1daf0bf, Windows OpenGL/RTX5070. 43 headless-набора (37752 проверка с окончательным model3029) прошли без ошибок; старые наборы сохранены, новые проверяют production UI. Старый интерфейс доступен только изолированным desktop-регрессиям через `--pr22-regression`, не Android-сборке. Все30 уровней воспроизведены через два нажатия в обеих ориентациях; Undo/прерывания/экономика/прогресс проверены.

Новые наборы: model3029, layout3894, navigation290, control10503, evolution364 headless/372 GPU, smoke3 headless/15 GPU. Навигация включает все16 предметов по прежним ценам, бесплатную смену дизайна, отмену preview, старые v2-сохранения, наблюдения, восстановление досье, touch-slider, быстрые свайпы и запрещённые входы. Проверены семь разрешений и горизонтальные аналоги, safe area и шрифт135%. Полные журналы остаются в игнорируемом `logs/tests/`.

Автоматический расчёт touch48dp проверен с заданной density. Android DisplayMetrics и системные вырезы требуют физической проверки: Windows не подтверждает их работу на Galaxy. Красивый финальный арт и ручная оценка читаемости/эргономики остаются за физическим плейтестом и отдельным PR24.
