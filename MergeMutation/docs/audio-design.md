# PR21 — Original Soundtrack & Adaptive Audio

## Происхождение и метод

Все девять композиций созданы для Merge Mutation в PR21 собственным офлайн-композитором `tools/audio/MutationScore.cs`. Нет заимствованных мелодий, записей, семплов, вокала, сторонних виртуальных инструментов, платных API или весов моделей. Локальная музыкальная модель с готовым runtime/весами не найдена; использован разрешённый альтернативный путь: нотная композиция, MIDI и многослойный синтез на CPU. RTX 5070 использовалась для проверки графики, а не для заявленной нейросетевой генерации.

Общий мотив: D–F–A–E–G–C (интервалы 0, 3, 7, 14, 5, 10), шесть нот с синкопированными длительностями. Гармоническая последовательность меняется между секциями; структура A / A′ / B / возврат, контрмелодии и барабанные заполнения. У каждого трека фиксированный seed 21700–21708. Исходный код содержит партитуру и тембры; это полноценные многослойные аранжировки, их художественное принятие остаётся за ручным прослушиванием.

Слои: гармонический detuned pad, гармонически насыщенный бас, FM-фетровое пианино/стекло, жидкая маримба со скольжением высоты, щипковая/язычковая линия, низкий синтезированный барабан, деревянный резонатор, шумовой шейкер, пузырьки/сонар и короткие стереоотражения. Комплекс спокойнее; портал и бестиарий разрежены; Слизик использует swing/маримбу; Рогач — более тяжёлые низкие барабаны; головоломка и песочница — более быстрый пульс и акценты.

## Реальные файлы и измерения

Все файлы — OGG Vorbis quality 3, stereo 44,1 kHz. Семь тем по 90/120 секунд и два одноразовых сигнала 4/5 секунд. Суммарно **7 161 109 байт / 6,83 MiB**, меньше 15 MiB. Нулевое число отсчётов с клиппингом у всех файлов; PCM peaks 0,494–0,679, RMS 0,120–0,125, максимальный скачок границы 0,006745 (~−43,4 dBFS). Источники ограничены peak 0,67 и RMS 0,125; после lossy-кодирования peak может немного отличаться. В исходнике кольцевые хвосты/отражения, удаление DC, короткий 5,8 ms taper границы; длинной тишины на повторе нет. Для джинглов fade края длиннее.

`check_soundtrack.ps1` декодирует каждый файл, сверяет длительность, размер, peak/RMS/clipped samples/границу и отдельно запускает EBU R128 true-peak/LUFS. Порог принятия seam <0,02, peak <0,95, длительность ±0,05 сек. Логи содержат полный анализ и SHA-256 каждого OGG. Наушники и телефон остаются обязательной ручной проверкой: численные проверки не удостоверяют отсутствие субъективно слышимых стыков, резких тембров или утомления.

## Лицензии инструментов

- Собственная партитура, MIDI и синтезатор в этом репозитории, без подключённых библиотек синтеза/семплов; оригинальные активы подготовлены для проекта. Новая лицензия на весь репозиторий не назначается.
- Кодирование/анализ — FFmpeg 9.0.2 essentials gyan.dev, скачанный по Windows-ссылке с [официальной страницы FFmpeg](https://ffmpeg.org/download.html). Локальная сборка имеет `--enable-gpl --enable-version3`; не следует называть эту конкретную сборку только LGPL. [Официальные условия FFmpeg](https://ffmpeg.org/legal.html) объясняют различие LGPL/GPL-сборок. Бинарник, архив и библиотеки FFmpeg не входят в игру или Git; это отдельный офлайн-инструмент генерации/аудита.
- Encoder `libvorbis` — Xiph Vorbis; [BSD-условия Xiph](https://xiph.org/licenses/bsd/) разрешают использование с указанными условиями распространения библиотек. Внешних медиасемплов, лицензируемых пакетов инструментов и моделей в созданном аудио нет. Runtime использует уже встроенный в Godot декодер и его существующие third-party notices.
- MP4-доказательство — конверсия собственной записи Godot через локальный FFmpeg/libx264; encoder не распространяется с игрой. MP4 — только документация, исключена из APK.

## Воспроизведение генерации

```powershell
./MergeMutation/tools/generate_soundtrack.ps1 -FFmpegPath 'C:/path/to/ffmpeg.exe'
./MergeMutation/tools/check_soundtrack.ps1 -FFmpegPath 'C:/path/to/ffmpeg.exe'
```

WAV 16-bit PCM и MIDI сохраняются только в `MergeMutation/.godot/audio-generation/source/`, вне экспортируемых ресурсов и Git. Логи измерений — `logs/tests/`. Нотные источники детерминированы; контейнер OGG другого encoder-build может получить другой SHA. В runtime входят только девять OGG и настройки импорта. На целевом телефоне нет зависимости от FFmpeg/.NET/моделей.

## Адаптивная система

`data/music.json` задаёт треки, локации, habitat_id, jingles и 1,5 s crossfade. `music_manager.gd`: два строго ограниченных фоновых проигрывателя и один jingle player. Частые переходы объединяются в последнее направление; после затухания старый player останавливается. Позиции тем запоминаются при выходе и используются при возвращении. Панель настроек не меняет контекст и не перезапускает тему.

Шины: Background → Music → Master; существующие эффекты: SFX → Master. Background level −7 dB; победа/открытие вида проигрываются последовательно, фон плавно приглушается ещё на 9 dB и возвращается после очереди. Тесты проверяют неограничивающееся наложение, pause/resume активного crossfade, обе индивидуальные темы и сохранение позиции.

Три слайдера сохраняются в существующем `merge_mutation_settings.cfg`, посторонние поля ConfigFile сохраняются. Старый enabled=false переносится в SFX=0, не выключает музыку. Mute до нуля использует bus mute. Application pause/focus loss приостанавливает аудио и tweens, resume продолжает их; завершённые Tween повторно не запускаются. Обычная Windows-потеря фокуса также приостанавливает музыку. Изолированный аудиотест отключает внешние события фокуса, чтобы скрытые окна CI не влияли на часы теста, и явно проверяет тот же метод suspend/resume.

Новые миры/вольеры подключаются через конфигурацию, без изменения списка условий в менеджере. UI маршрутизирует текущие известные экраны. Аудио не меняет экономику или исход игры.

## Результаты и ручная приёмка

55 автоматических проверок: декодирование, длительность/loop flags, объём, старт, все семь контекстов, быстрые переходы, bounded voices, сохранение позиции, очередь победа→открытие, duck/restore, независимые шины, сохранение настроек и восстановление crossfade. Нативный декодер Godot проверен headless и Windows GPU. Все девять ресурсов находятся в подписанной debug APK.

Производительность: нет runtime-синтеза музыки, подгружаются сжатые Vorbis-потоки; одновременно до двух фоновых потоков при crossfade плюс короткий сигнал и прежние SFX. Регрессии и запись интерфейса прошли на RTX 5070. Android CPU/RAM/батарея/нагрев пока не измерены; не делаем выводов об их значениях. Форма [core-gameplay-loop-playtest.md](core-gameplay-loop-playtest.md) включает оценки каждой темы, стыков, переходов и общей атмосферы.
