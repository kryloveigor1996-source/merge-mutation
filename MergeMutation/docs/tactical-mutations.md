# Tactical Mutation Prototype — технический отчёт

Основа: актуальный `main` с объединённым PR №11 (`549f032`). Ветка `experiment/tactical-mutations`. Основная кампания, каталог и SaveCodec не изменены.

## Реализация и файлы

- `scripts/mutation_session.gd`: небольшое расширение существующей CampaignSession. Повторно использует начальную раскладку, создание, форматы целей, счётчики, слияния, лимиты, копирование состояний. Добавляет местность, детерминированные способности, конечные позиции и их валидацию. Никаких вызовов сохранения или наград.
- `scripts/mutation_search.gd`: поиск минимального количества ходов по настоящим переходам сессии. Бесплатные создания учитываются алгоритмом Дейкстры; лимит состояний явно возвращает cutoff. UI не запускает решатель и не блокируется поиском.
- `scripts/mutation_experiment.gd`: отдельный непрозрачный экран, пять испытаний, выделение действий, mouse/touch, перезапуск, выход, временные галочки и обучение; лёгкие Tween/процедурные эффекты. Клетки 56×56, интерфейс 360×720 внутри существующей адаптации LabView.
- `scripts/lab_view.gd`: временная кнопка входа, закрытие экспериментального экрана при навигации. Нижняя панель вмещает четыре кнопки шириной 82 px; в основной кампании эксперимент отключён.
- `experiment/levels/level_01.json` … `level_05.json`: пять отдельных конфигураций. Нулевые награды, исходные ID видов, явная местность, отсутствующие клетки, условия победы, лимиты и подсказки.
- `tests/mutation_test.gd`: поиск, контрфактические доказательства, воспроизведение, отрицательные правила и валидация.
- `tests/mutation_ui_test.gd`: реальные mouse/touch события, вход из лаборатории, все пять побед, защита повторного нажатия, перезапуск/выход, переключение выбора и неизменность сохранённого профиля. Тот же сценарий запускается headless и с GPU; GPU дополнительно создаёт снимки.
- `tests/mutation_solutions.json`: сгенерированные свидетельства; не заменяют повторный поиск в тестах.
- `docs/tactical-playtest.md`, `README.md`, снимки `docs/mutation-*.png` и соответствующие Godot `.uid`/`.import`.

Нет изменений в прежних `campaign/levels`, экономике, звёздах, species_id/evolution_stage, системе бустеров, картах, порталах или коллекции. Экспериментальные способности действуют только в экспериментальной сессии и не меняют поведение тех же видов в кампании/песочнице.

Все **56 GDScript-файлов** проходят холодную компиляцию. Финальный полный импорт, повторный импорт и запуск основной сцены без ошибок/предупреждений. GPU: NVIDIA RTX 5070, OpenGL Compatibility, 360×720. `git diff --check` чистый. Тестовые профили и логи остаются в игнорируемой `.godot/`; UI-тест сравнивает содержимое сохранённого профиля побайтно после каждой победы. Прежние тесты сохранений v2, коллекции, десяти решений кампании, телепорта, порталов, предпросмотра, отсутствия повторной награды и больших карт сохранены.

Для уровней 1–5 доказаны минимумы **4, 3, 2, 9, 8 ходов**; лимиты **6, 5, 4, 11, 10**. Поиск посетил соответственно **21, 10, 5, 503, 2436** состояний до оптимального решения. Ни один из проверочных поисков не достиг cutoff. Отдельный поиск с каждой необходимой способностью, выключенной по очереди, не находит обхода. Поиск с лимитом на один ход меньше минимума также исчерпывается без победы. Пять свидетельств воспроизведены и напрямую движком, и интерфейсом.

```text
godot --headless --path . --script res://tests/mutation_test.gd
godot --headless --path . --script res://tests/mutation_ui_test.gd
godot --path . --script res://tests/mutation_ui_test.gd
```

```powershell
./tools/check_gdscript.ps1 -GodotPath 'C:/path/to/godot.exe'
```

Остальные команды регрессии — в README. При повторном запуске mutation_test свидетельства пишутся только в `.godot/mutation-solutions.json`. Переносить их в отслеживаемый файл следует после изменения раскладок и успешных доказательств, а не подменять ими тест.

## Ограничения

Нет постоянных сохранений экспериментального прогресса или обучения, полного автоматического анализа тупика во время игры, конечных художественных ассетов и оценки интересности реальными игроками. APK и физическое Android-устройство не проверены. Таймер, три звезды, покупки, реклама, новые миры и изменение наград не реализовывались. Основная ручная проверка: понятность правила прыжка и целевых меток, переключение видов, ощущение разных решений в задачах 4–5 и удобство четырёх нижних кнопок на телефоне.
