# Sound slots

Current sounds are generated by original code in `scripts/lab_audio.gd`; no
third-party recordings, plugins or paid services are used. The four short mono
effects are synthesized in memory as 16-bit PCM at 22,050 Hz.

To replace a sound, add your own licensed WAV or OGG file:

- `spawn.wav` — creature creation
- `select.wav` — creature selection
- `merge.wav` — normal merge
- `discover.wav` — first discovery of a higher level

`.ogg` is also supported; WAV takes precedence if both exist. Missing slots use
the synthesized sound. Each slot has its own AudioStreamPlayer. Settings can mute
all effects; preference is stored separately in `user://merge_mutation_settings.cfg`.
Gameplay progress remains in the existing `merge_mutation_save.json` format.
